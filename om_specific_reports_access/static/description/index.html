Hide Specific Print Reports Per User

Hide specific print reports per user basis. Unlike hiding all reports for a model, this module lets you select exactly which reports to hide — giving you granular control over print report visibility.

✨ What it does

  • ✅Hide specific print reports — not all reports for a model.
  • ✅Per user granular control over specific reports.
  • ✅Select model first, then choose which reports to hide.
  • ✅Works independently of group permissions.

🛠 How it works

  • Adds a Hide Specific Print Reports tab to the user form.
  • Select a model (e.g., Sale Order) to see available reports.
  • Choose specific reports to hide (e.g., hide Quotation but keep Sales Order).
  • Selected reports are filtered from the Print menu for that user.

⚙️ Configuration: Specific Print Report Control

  1. Install the module from Apps.
  2. Go to Settings → Users & Companies → Users.
  3. Open the user for whom you want to hide specific print reports.
  4. Navigate to the Hide Specific Print Reports tab.
  5. Click "Add a line" and select a Model (e.g., sale.order).
  6. Select the specific reports to hide from the Reports to Hide field.
  7. Save and refresh the browser — changes take effect immediately.

Quick Tip: You can add multiple lines — one for each model where you want to hide specific reports.
