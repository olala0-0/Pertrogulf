Advanced Login History & User Audit Log

Advanced Login History is a powerful Odoo 19 module designed to help administrators monitor user login sessions, failed login attempts, logout activity, and complete user access details in one organized place.


The module captures important session information such as user name, login time, logout time, IP address, browser, operating system, device details, location, and session duration. It also provides clear visibility into active sessions and user access behavior.


Along with login tracking, it includes advanced user audit logs to track create, update, and delete actions performed on configured Odoo models. Administrators can review old and new values, monitor model-wise activities, open related records, and maintain a reliable audit trail for better security and control.

Browser Location Permission

Advanced Login History requests browser location permission to capture accurate user login location details inside Odoo.


When the user allows location access, the module records latitude, longitude, city, country, IP address, browser, device, and session details for better security tracking.
