Branch Dimension: Base

One list of branches for every app that needs one

Overview

A branch is not an app. It is a dimension that several apps have to agree on - sales, purchase, accounting, inventory, helpdesk, subscriptions. The moment each app keeps its own list, the same shop exists three times under three different names, and nothing can be reported across them.

This module holds the branch and nothing else: the list, the field the other modules reuse, who may see which branch, and the default a new document picks up. You do not install this one on its own - you install the branch module for the app you actually run, and it brings this along.

What is in it

  • The branch itself: code, name, manager, address, company
  • A reusable field (ms.branch.mixin) so every document names it the same way and checks the company the same way
  • Access rights per branch: two opt-in groups - own branches only, or all branches
  • A default that follows the person, filled in on new documents through default_get - so installing the module never back-fills years of history
  • Restriction that takes effect at once: the rule cache is cleared when somebody's branches change, instead of waiting for a restart

It changes nothing on its own: until somebody is put in one of the two groups, everybody keeps seeing everything.

The Branch List Every App Reads From

One list, kept in Settings next to Users and Companies. Code, name, the manager who answers for it, the address it trades from, and the company it belongs to.

The code is what shows up everywhere else, so a branch stays recognisable in a list column that is forty pixels wide.

the branch itself, and nothing that belongs to any one app

Who May See Which Branch

Two opt-in groups: own branches only, or all branches. A person outside both is unrestricted, so installing this module changes nothing until somebody decides it should.

The default branch is filled in on new documents through default_get, never as a column default - so switching it on does not quietly back-stamp years of history with a branch nobody chose.
