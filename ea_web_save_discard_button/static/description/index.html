Frequently Asked Questions

Find quick answers to common questions about Save & Discard Buttons.

What does this module do?

It adds clearly labeled Save and Discard buttons to the Odoo form status bar, making record changes easier to confirm or cancel.

Where are the Save and Discard buttons available?

They are available in Odoo form editing workflows where records can be modified and saved or discarded.

What does the Save button do?

The Save button confirms the current changes and applies them to the record.

What does the Discard button do?

The Discard action cancels the current edits and restores the record to its previous state.

Is it compatible with Odoo 19?

Yes, this module is designed for Odoo 18 and integrates with the standard Odoo web form editing interface.
